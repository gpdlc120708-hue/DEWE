Definición de CSS Lenguaje de hojas de estilo que controla la apariencia (colores, fuentes, diseño) de un documento HTML
Especificación Oficial de CSS Estándar mantenido por el W3C, organizado actualmente en módulos independientes que evolucionan por separado
Funcionamiento Básico El navegador crea un modelo de estilos (CSSOM), lo une al contenido (DOM) y pinta el resultado en pantalla
Formas de Inclusión Externa: Archivo. Interna: Etiquetas. En línea: Atributo
Glosario Básico Regla: Bloque completo de estilos. Propiedad: El aspecto a cambiar. Valor: El ajuste aplicado
Uso de Comentarios Notas invisibles para el navegador que se encierran entre /* y */
Sintaxis Se escribe como propiedad: valor; dentro de llaves {}. El punto y coma es obligatorio al final
Selectores Patrones para elegir qué elementos estilizar: por etiqueta (h1), por clase (.boton) o por ID (#menu)
Agrupación Aplicar un mismo estilo a varios selectores separándolos con comas: h1, p, span
Herencia Es el mecanismo por el cual ciertas propiedades aplicadas a un elemento padre
Colisiones Conflictos que se resuelven por cascada (orden de aparición) y especificidad (el selector más preciso gana)
Unidades Absolutas: Medidas fijas como px. Relativas: Medidas flexibles como %, em, rem o vh
Colores Definidos por nombre (red), código hexadecimal (#FF0000), rgb() o hsl()

Box Model Anchura y Altura: Define el tamaño total de un elemento sumando su contenido, relleno (padding), borde y márgenes
Margen y relleno: Padding (Relleno): Espacio interno entre el contenido y el borde. Margin (Margen): Espacio externo que separa al elemento de otros.
Bordes: delimitan el área del elemento.
Margen, relleno, bordes y boxmodel: La suma de estos elementos determina el tamaño total del elemento en pantalla.
Fondos: Propiedades como background-color o background-image que visten el área del contenido y el relleno (pero no el margen)
Posicionamiento y Visualización Tipos de elementos: Block (Bloque): Ocupan todo el ancho disponible. Inline (En línea): Solo ocupan el espacio de su contenido.
Posicionamiento normal: Es el flujo natural del navegador (posición static). Los elementos aparecen uno tras otro según el orden del HTML
Posicionamiento float: Empuja un elemento a la izquierda o derecha (float: left/right), permitiendo que el texto u otros elementos fluyan a su alrededor
Posicionamiento absoluto: El elemento se sale del flujo normal y se posiciona respecto a su ancestro posicionado más cercano usando top, bottom, left y right
Visualización: Se controla con la propiedad display. Permite cambiar la naturaleza de un elemento (ej. convertir un enlace en bloque) o esconderlo completamente con display: none
Texto Tipografía: Se controla con font-family (fuentes), font-size (tamaño), font-weight (grosor como bold) y font-style (italic). Permite usar fuentes del sistema o externas (como Google Fonts)
Propiedades de Texto: Se refiere a la alineación (text-align), decoración como el subrayado (text-decoration), transformación a mayúsculas (text-transform) y el espaciado entre letras o líneas (line-height)
Enlaces Los enlaces () se estilizan según su estado mediante pseudoclases: link (estado normal), visited (enlace ya visitado), hover (cuando el ratón está encima), active (al hacer clic).
Imágenes Se pueden manipular para que sean responsivas usando max-width: 100%. Otras propiedades comunes incluyen el ajuste de proporciones (object-fit), redondeo de esquinas (border-radius) y filtros visuales (filter)
Listas Se aplican a etiquetas ul y ol. Las propiedades clave son: list-style-type: Cambia el símbolo (puntos, números, letras, o none para quitarlos), list-style-image: Permite usar una imagen personalizada como viñeta, list-style-position: Define si la viñeta está dentro o fuera del margen del texto.
Tablas Se enfocan en mejorar la legibilidad del contenido tabular: border-collapse: Une los bordes de las celdas en uno solo (evita bordes dobles), padding: Espaciado dentro de las celdas (th y td), nth-child(even): Se usa frecuentemente para crear filas con colores alternos (efecto cebra).
Formularios CSS permite personalizar elementos que por defecto son difíciles de estilizar: Inputs y Textareas: Se ajustan bordes, rellenos y el resaltado al hacer clic (:focus), Botones: Se cambian colores de fondo, bordes y el cursor (cursor: pointer), Alineación: Se suelen usar técnicas de Flexbox para alinear etiquetas (labels) con sus campos de entrada
