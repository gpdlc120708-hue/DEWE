Calculadora de Areas (Figuras Planas)

Selecciona una figura, ingresa los valores y al calcular se usará if/else para elegir la fórmula correcta.

➡ Elige una figura para comenzar

💡 Cambio de Figura. Ingresa las variables y presiona "Calcular Área"
🔍 Estructura de selección (if-else if) en acción:
Al hacer clic en "Calcular", el programa evalúa la figura activa y ejecuta la fórmula correspondiente.
• Variables: almacenan base, altura, radio, etc.
• Operadores: *, /, **, Math.PI, etc.
• Selección: if (figura === "cuadrado") { ... } else if (...) { ... }
✅ Refuerzo práctico: Declaración de variables, operadores aritméticos, control de flujo con if/else
